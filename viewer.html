Relational SQL Query (Interview Talking Point)

SELECT 
    c.id, c.first_name, c.email,
    COUNT(e.id) AS total_events,
    COALESCE(SUM(CASE WHEN e.event_type = 'PURCHASE' THEN e.monetary_value ELSE 0 END), 0.0) AS total_spend,
    MAX(e.event_timestamp) AS last_active_at
FROM customers c
LEFT OUTER JOIN events e ON c.id = e.customer_id
GROUP BY c.id, c.first_name, c.email
ORDER BY total_spend DESC, total_events DESC;

Why this query matters: Demonstrates conditional aggregation with SUM(CASE ...) and LEFT OUTER JOIN to ensure customers with 0 events are not silently dropped from marketing reporting.

Speedup Ratio: 21.16x Faster

The composite B-Tree index on (customer_id, event_type, event_timestamp) transforms a full sequential scan of 50,000 event rows into pinpoint index lookups. Correlated subqueries (EXISTS and NOT EXISTS) terminate on the very first matching index leaf page, saving massive disk I/O and CPU cycles.
